GroomLab is a hair, fur and feather system for Maya. It combines **hierarchical guides** that you
shape by hand (primary guides, and child guides generated inside their parents' tubes) with a
**procedural node graph** that generates the render strands from them (scatter, interpolate,
clump, noise, curl and so on).

<Callout type="info" title="Early access">
  GroomLab is in early access and under active development. Grooming, rendering and export work
  today; nodes, tools and defaults will continue to change. [What's new](/docs/whats-new) lists
  changes per release. Send feedback and bug reports to
  [support@getgroomlab.com](mailto:support@getgroomlab.com).
</Callout>

## Where things are in Maya

| Window | Contents |
| --- | --- |
| **Attribute Editor** (groom shape) | Inputs (scalp, rest mesh, guides, colliders), keyable controls, display and render settings. |
| **Groom Tools** | Guide brushes, guide groups, painted maps, sculpt layers (correctives) and reference photos. |
| **Graph Editor** | The node graph that generates the strands. |

Every UI action has a Python equivalent in the `groomlab` package ([Python API](/docs/python-api)).

The standalone [GroomLab app](/docs/app) (grooming, look-dev and export without Maya) and
[GroomLab for Blender](/docs/blender) are in beta on Windows. Both open grooms made in Maya
without conversion.

## Requirements

- **Maya 2022** on Windows (64-bit) is tested. **Maya 2023 to 2027** are in beta: the download
  includes a build for each, compiled against that Maya version but not yet tested in it. The Maya
  2024 build has no Arnold translator yet.
- **MtoA** (the Arnold plug-in that ships with Maya) to render in Arnold.
- If Maya reports a missing DLL, install the latest *Microsoft Visual C++ Redistributable for
  Visual Studio 2015-2022 (x64)*.
