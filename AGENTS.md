# Project instructions

- Keep all code changes, commits, and testing local unless the user explicitly asks to publish them.
- Never push branches or commits, create or update pull requests, or otherwise change GitHub state without an explicit instruction from the user for that specific publish action.
- Approval to implement or fix something does not imply approval to push it, even when an existing pull request is open.
- Name chats for GitHub issue work as `Issue #<number> - <issue title>`, using the issue's exact title.
- When Codex submits a pull request, credit Codex on its commits with the trailer `Co-authored-by: Codex <codex@openai.com>`.
